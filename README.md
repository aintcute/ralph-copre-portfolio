# Ralph Copre — Graphic Design Portfolio

A responsive, dark-themed portfolio website for Ralph Laurence D. Copre.

## Included
- `index.html` — portfolio content and structure
- `style.css` — responsive dark visual design
- `script.js` — mobile navigation interaction
- `assets/` — portfolio cover and selected project images
- `Ralph-Copre-Graphic-Design-Portfolio.pdf` — downloadable PDF portfolio

## Publish with GitHub Pages
1. Create a new **public** GitHub repository named `ralph-copre-portfolio`.
2. Upload all files and folders in this package to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Your site will appear at `https://YOUR-GITHUB-USERNAME.github.io/ralph-copre-portfolio/` after deployment.
